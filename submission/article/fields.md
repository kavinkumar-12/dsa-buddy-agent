DSA Buddy: a personal DSA tutor that classifies before it teaches with Strands Decider 2B

Description (max 512 characters):
DSA Buddy is a personal DSA tutor for college students that uses Strands Decider 2B to classify each student request (concept, code, debug, practice, compare, off-topic) before the LLM responds, so the right teaching tool runs. The decider hit 100% accuracy and ran 30x faster than the LLM on 10 labelled cases.
